Installe AlphaScope sur ton iPhone

Trois gestes dans Safari, et l'appli a son icône sur ton écran d'accueil.

  1. 1. Touche le bouton Partager en bas de Safari (le carré avec une flèche).

  2. 2. Fais défiler et choisis Sur l'écran d'accueil.

  3. 3. Touche Ajouter, puis ouvre AlphaScope depuis son icône.

Les notifications ne marchent que dans l'appli ouverte depuis l'écran d'accueil (iOS 16.4 ou plus).

Ta clé

Une clé GitHub permet à l'appli de lire tes chiffres et d'envoyer tes saisies. Elle reste sur cet iPhone.

  1. Ouvrir la page de création de clé
  2. Token name : AlphaScope iPhone · Expiration : la plus longue proposée (un an).
  3. Repository access : Only select repositories → AlphaScope.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Generate token, puis copie la clé (elle commence par github_pat_).

Ta clé peut lire tes chiffres, mais pas envoyer tes saisies. Pour tout faire depuis l'appli, mets « Contents » sur « Read and write » et recolle la clé.
